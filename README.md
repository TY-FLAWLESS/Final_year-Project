# UniMart

UniMart is a web-based online marketplace for buying and selling goods and services within the Kumasi Technical University campus community.

## Project Structure

- `frontend/` — Angular application
- `backend/` — Node.js + Express API
- `database/` — SQL schema and seed data
- `docs/` — project documentation and diagrams
- `screenshots/` — UI screenshots

## Tech Stack

- Frontend: Angular, Bootstrap
- Backend: Node.js, Express.js, MySQL
- AI Search: OpenAI API + NLP

## Getting Started

1. Open the frontend folder and install Angular dependencies.
2. Open the backend folder and install server dependencies.
3. Configure your MySQL connection in `.env`.
4. Start the backend API and frontend app.
